# NiKillya

Сайт автомастерской с онлайн-записью. Два поста, легковые любых марок,
заявка уходит мастеру в Telegram.

Требования и решения по проекту — в [дискавери-брифе](docs/discovery.html),
живая версия: https://claude.ai/code/artifact/e3387b1d-52e1-427c-abca-7d2111998fe0

## Главное про архитектуру

**Сайт не хранит персональные данные.** Расписанию они не нужны: чтобы слот был
занят, базе достаточно знать «пост 1, вторник 14:00, замена колодок». Имя,
телефон и VIN складываются в текст сообщения, уходят мастеру в Telegram и в базу
не пишутся. Логирование тела запроса отключено намеренно — см. комментарий
в `app/api/bookings/route.ts`.

**Двойная запись невозможна на уровне базы.** Каждая бронь материализует
получасовки, которые занимает, в таблицу `SlotHold` с уникальным индексом
на паре «пост и начало слота». Проверять занятость перед записью бессмысленно:
между проверкой и вставкой успевает вклиниться параллельный запрос.

**Статус ремонта меняется по подписанной ссылке, а не через админку.** Админки
нет по решению владельца, но статус кто-то должен переключать. Вместе с заявкой
мастеру уходит ссылка с HMAC-подписью: чат личный, ссылка привязана к одной
брони. Клиент смотрит статус по короткому коду, который ничего изменить
не позволяет. Отмена возвращает время в продажу, «готово» — нет: работа заняла
этот слот по факту.

**Порядок операций в `lib/booking.ts` — несущая конструкция.** Слот занимается
первым, статус переводится в `new` только после успешной отправки в Telegram,
а при неудачной отправке бронь удаляется целиком. Занятый слот, о котором мастер
не знает, хуже честного «не получилось, напишите напрямую».

## Запуск

```bash
npm install
cp .env.example .env      # заполнить TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
npx prisma migrate dev
npm run db:seed
npm run dev
```

Без токена бота форма примет данные, но вернёт 503 и предложит написать
напрямую — бронь при этом не создастся.

### Переменные окружения

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | Локальная SQLite. По умолчанию `file:./dev.db` |
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | Числовой id чата мастера |
| `TELEGRAM_API_BASE` | Необязательная. Адрес API — чтобы прогнать запись против мока, не трогая живого бота |
| `BOOKING_SECRET` | Секрет для подписи ссылок мастера, минимум 16 символов. `openssl rand -hex 32` |
| `SITE_URL` | Адрес сайта — из него собираются ссылки в сообщениях мастеру |

## Команды

```bash
npm run dev        # разработка
npm run build      # прод-сборка
npm test           # тесты логики расписания и сообщений
npm run lint       # eslint
npm run db:seed    # загрузить услуги из data/services.csv
npm run db:reset   # пересоздать базу и засеять заново
```

## Что где лежит

| Путь | Что это |
|---|---|
| `lib/schedule.ts` | Вся работа со временем: сетка, свободные слоты, рабочие дни |
| `lib/booking.ts` | Создание брони и порядок операций |
| `lib/availability.ts` | Свободное время на день |
| `lib/telegram.ts` | Единственное место, которое видит контакты клиента |
| `lib/validation.ts` | Проверка формы. Без импорта базы — чтобы тесты не поднимали Prisma |
| `lib/tokens.ts` | Подпись ссылок мастера |
| `lib/status.ts` | Статусы брони и допустимые переходы |
| `app/z/[code]` | Статус записи для клиента |
| `app/m/[token]` | Управление записью для мастера |
| `data/services.csv` | Услуги и длительности. [Откуда числа](data/README.md) |
| `docs/discovery.html` | Бриф: конкуренты, применимость скилов, опрос, план |

## Что осталось сделать

- **Рабочие часы — допущение.** Сейчас Пн–Сб, 09:00–19:00, в `lib/schedule.ts`.
  В опросе их не спрашивали, надо подтвердить у владельца до публикации.
- **Цены не проставлены.** Поле `priceFrom` пустое, на сайте пока «цену мастер
  назовёт после осмотра». Прайс есть на бумаге — нужно перенести в CSV.
- **Длительности выверить.** 24 из 29 позиций — типовые оценки, а не нормативы.
  На двух постах ошибка в полчаса за день превращается в сорванный слот.
- **SMS-напоминания** конфликтуют с решением не хранить телефон. Отдельный разговор.
- **Кнопки статуса прямо в Telegram** вместо ссылки — удобнее, но требуют
  вебхука, а значит публичного адреса. Вернуться, когда появится хостинг.
- **Правовой и налоговый статус** деятельности — вопрос к юристу, не к коду.
